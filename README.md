# Élora Estates — International Realty Luxury Portal

A modern, high-end editorial web portal for **Élora Estates International Realty**, showcasing ultra-luxury architectural residences, villas, penthouses, and private estates.

## 🌟 Pages Overview
- **Home (`index.html`)**: Cinematic hero sanctuary, floating glass search, curated portfolio highlights, and newsletter.
- **Properties Listing (`properties.html`)**: Filterable luxury catalog with multi-typology search, pricing, and suite count.
- **Property Details (`property-details.html`)**: Architectural dossier, floor plans, specs, private gallery, and viewing consultation.
- **About Us (`about.html`)**: Maison heritage, founding ethos, leadership team, and global salons.
- **Contact (`contact.html`)**: Private office inquiries, consultation booking, and global salon locations.
- **Client Portal (`login.html`)**: Discreet invitation-only client authentication sanctum.

## 🚀 Running Locally
To launch the website locally:
```bash
python server.py 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS** (via CDN)
- **Google Fonts** (Playfair Display & Plus Jakarta Sans)
- **Google Material Symbols**
